# Figure captions

All figures are numerical results generated by `python examples/reproduce.py` from declared model inputs. They are not experimental profiles.

- `boron_profiles.png`: initial reflected-Gaussian chemical boron concentration and final 950 °C / 1000 °C anneal profiles. The dotted line is a reporting threshold of 10^17 cm^-3. The concentration axis is logarithmic; the view omits concentrations below 10^13 cm^-3 and unused depth past the modelled visible tail. The CSV profiles retain the full 2 µm computational domain.
- `thermal_schedules.png`: supplied piecewise-linear ramp/hold/ramp schedules. The temperature axis is in °C and the time axis is in minutes.
- `sensitivity.png`: deepest concentration-threshold crossing in nm as a function of a declared diffusivity multiplier or absolute temperature offset in K. It is an input sensitivity study, not a statistical confidence interval or electrical junction-depth measurement.
